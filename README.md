# Sprint 3 - Testes de Aplicação Web

Projeto prático de Quality Assurance desenvolvido durante a formação na TripleTen.

## Sobre o projeto

Este projeto apresenta atividades de testes manuais e funcionais realizadas em uma aplicação Web.

Foram elaborados checklists para verificar diferentes elementos e funcionalidades da aplicação, registrando os resultados dos testes em diferentes ambientes.

## Atividades realizadas

- Elaboração de checklists de teste;
- Testes de layout;
- Validação de textos e elementos da interface;
- Verificação de botões e componentes visuais;
- Execução dos testes em diferentes ambientes;
- Registro dos resultados como aprovado ou reprovado;
- Identificação e registro de bugs.

## Exemplo de validação

Entre as verificações realizadas estão:

- Texto apresentado na opção "Carsharing";
- Informação de duração da viagem;
- Botão "Reservar";
- Elementos visuais da aplicação.
